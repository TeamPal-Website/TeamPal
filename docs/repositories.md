# Репозитории

## `src.repositories.admins`

Административные операции над учётными записями пользователей.

### class `AdminsRepository`

Репозиторий для административных действий над сохранёнными учётными записями пользователей.

#### `async def block_user(user_id)`

Деактивирует учётную запись пользователя.

- **user_id** — Первичный ключ пользователя для блокировки.

- **user_id** — Первичный ключ пользователя для разблокировки.
- **`UserNotFound`** — Если пользователь с указанным id не найден.



## `src.repositories.applications`

Доступ к данным откликов на вакансии.

### class `ApplicationsRepository`

Репозиторий для сохранённых записей откликов на вакансии.

#### `async def get_with_context(application_id)`

Загружает отклик с контекстом связанного проекта и вакансии.

- **application_id** — Первичный ключ отклика.
- **Возвращает** — Отклик с метаданными проекта или ``None``.
  - *тип* `ApplicationWithContext | None`

#### `async def get_my_applications(profile_id, status=None, resume_id=None, limit=20, offset=0)`

Возвращает отклики профиля на проекты других пользователей.

- **profile_id** — Идентификатор профиля соискателя.
- **status** — Необязательный фильтр по статусу.
- **resume_id** — Необязательный фильтр по резюме.
- **limit** — Максимальное количество возвращаемых строк.
- **offset** — Количество пропускаемых строк.
- **Возвращает** — Отклики с контекстом проекта, сначала самые новые.
  - *тип* `list[ApplicationWithContext]`

#### `async def count_my_pending(profile_id)`

Подсчитывает исходящие отклики профиля в статусе ожидания.

- **profile_id** — Идентификатор профиля соискателя.
- **Возвращает** — Количество откликов в ожидании на внешние проекты.
  - *тип* `int`

#### `async def count_incoming_pending_for_owner(owner_profile_id)`

Подсчитывает отклики соискателей в ожидании по проектам владельца.

- **owner_profile_id** — Идентификатор профиля владельца проекта.
- **Возвращает** — Количество непросмотренных откликов в ожидании.
  - *тип* `int`

#### `def _employer_applications_base_select()`

_Нет описания._

#### `async def get_for_project_owner(project_id, status=None, limit=50, offset=0)`

Возвращает отклики, полученные по одному проекту.

- **project_id** — Первичный ключ проекта.
- **status** — Необязательный фильтр по статусу.
- **limit** — Максимальное количество возвращаемых строк.
- **offset** — Количество пропускаемых строк.
- **Возвращает** — Сводные данные откликов для владельца.
  - *тип* `list[ApplicationForOwner]`

#### `async def get_for_profile_owned_projects(owner_profile_id, project_id=None, status=None, limit=50, offset=0)`

Возвращает отклики по проектам, принадлежащим профилю.

- **owner_profile_id** — Идентификатор профиля владельца проекта.
- **project_id** — Необязательный фильтр по проекту.
- **status** — Необязательный фильтр по статусу.
- **limit** — Максимальное количество возвращаемых строк.
- **offset** — Количество пропускаемых строк.
- **Возвращает** — Сводные данные откликов для владельца.
  - *тип* `list[ApplicationForOwner]`

#### `async def count_new_for_project(project_id, last_seen_at)`

Подсчитывает отклики соискателей, созданные после последнего просмотра.

- **project_id** — Первичный ключ проекта.
- **last_seen_at** — Время последнего просмотра откликов владельцем; если ``None``, учитываются все.
- **Возвращает** — Количество новых откликов.
  - *тип* `int`

#### `async def get_detail_for_owner(application_id)`

Загружает полное детальное представление отклика для владельца.

- **application_id** — Первичный ключ отклика.
- **Возвращает** — Подробный отклик с данными резюме соискателя или ``None``.
  - *тип* `ApplicationForOwnerDetail | None`

#### `async def cancel_pending_for_resume(resume_id, reason)`

Отменяет все отклики в ожидании для резюме.

- **resume_id** — Первичный ключ резюме.
- **reason** — Причина отмены для сохранения.
- **Возвращает** — Идентификаторы отменённых откликов.
  - *тип* `list[int]`

#### `async def cancel_pending_for_project(project_id, reason)`

Отменяет все отклики в ожидании по вакансиям проекта.

- **project_id** — Первичный ключ проекта.
- **reason** — Причина отмены для сохранения.
- **Возвращает** — Пары ``(application_id, resume_id)`` отменённых откликов.
  - *тип* `list[tuple[int, int]]`

#### `async def cancel_open_for_project(project_id, reason)`

Отменяет отклики в ожидании и принятые по вакансиям проекта.

- **project_id** — Первичный ключ проекта.
- **reason** — Причина отмены для сохранения.
- **Возвращает** — Пары ``(application_id, resume_id)`` отменённых откликов.
  - *тип* `list[tuple[int, int]]`

#### `async def set_status(application_id, status, cancel_reason=None)`

Обновляет статус отклика и необязательную причину отмены.

- **application_id** — Первичный ключ отклика.
- **status** — Новый статус отклика.
- **cancel_reason** — Необязательная причина отмены при переходе в cancelled.

#### `async def get_owner_user_id_for_application(application_id)`

Определяет идентификатор пользователя владельца проекта для отклика.

- **application_id** — Первичный ключ отклика.
- **Возвращает** — Идентификатор пользователя владельца или ``None``, если отклик не существует.
  - *тип* `int | None`

#### `async def get_applicant_user_id_for_application(application_id)`

Определяет идентификатор пользователя соискателя для отклика.

- **application_id** — Первичный ключ отклика.
- **Возвращает** — Идентификатор пользователя соискателя или ``None``, если отклик не существует.
  - *тип* `int | None`

#### `async def has_blocking_application_for_user_vacancy(user_id, vacancy_id)`

Проверяет, есть ли у пользователя блокирующий отклик на вакансию.

Блокирующими статусами являются pending, accepted и rejected.

- **user_id** — Идентификатор пользователя соискателя.
- **vacancy_id** — Первичный ключ вакансии проекта.
- **Возвращает** — ``True``, если существует блокирующий отклик.
  - *тип* `bool`



## `src.repositories.base`

Обобщённый асинхронный слой репозитория SQLAlchemy.

### `def _dump_for_orm(data, exclude_unset=False)`

Сериализует Pydantic-модель для вставки или обновления через SQLAlchemy ORM.

Рекурсивно преобразует значения ``Enum`` в их скалярные значения.

- **data** — Экземпляр Pydantic-модели для сериализации.
- **exclude_unset** — Если ``True``, не включать поля, которые не были явно заданы.
- **Возвращает** — Обычный словарь, подходящий для ``.values(**...)`` в операторах SQLAlchemy.
  - *тип* `dict`

### class `BaseRepository`

Базовый CRUD-репозиторий, сопоставляющий строки ORM со схемами Pydantic.

Подклассы задают ``model`` (класс SQLAlchemy ORM) и ``schema`` (класс Pydantic).

#### `def __init__(session)`

Привязывает асинхронную сессию SQLAlchemy.

- **session** — Активная асинхронная сессия базы данных.

#### `async def add(data)`

Вставляет новую строку и возвращает проверенный экземпляр схемы.

- **data** — Данные для вставки.
- **Возвращает** — Созданная сущность в виде схемы Pydantic.
  - *тип* `BaseModel`

#### `async def get_one_or_none(**filter_by)`

Возвращает одну строку по фильтрам равенства или ``None``.

- **Возвращает** — Подходящий экземпляр схемы или ``None``, если не найдено.
  - *тип* `BaseModel | None`

#### `async def get_filtered(*filter, **filter_by)`

Возвращает все строки по необязательным SQL- и equality-фильтрам.

- **Возвращает** — Список подходящих экземпляров схемы.
  - *тип* `list[BaseModel]`

#### `async def get_all(*args, **kwargs)`

Возвращает все строки для модели данного репозитория.

- **Возвращает** — Список экземпляров схемы.
  - *тип* `list[BaseModel]`

#### `async def edit(data, exclude_unset=False, **filter_by)`

Обновляет строки по фильтрам равенства.

- **data** — Поля для записи.
- **exclude_unset** — Если ``True``, обновлять только явно заданные поля.
- **Возвращает** — Количество обновлённых строк.
  - *тип* `int`

#### `async def delete(**filter_by)`

Удаляет строки по фильтрам равенства.

- **filter_by** — Фильтры равенства столбцов, передаваемые в ``filter_by``.

#### `async def count(**filter_by)`

Подсчитывает строки по фильтрам равенства.

- **Возвращает** — Количество строк.
  - *тип* `int`

### class `ResumesRepository`

Репозиторий для сохранённых записей резюме.

#### `async def search_public()`

Ищет публичные резюме со статусом поиска работы без назначения.

- **q** — Текстовый запрос для поиска по должности, разделу «о себе» и полям опыта.
- **city_id** — Фильтр по идентификатору города.
- **employment_intent** — Фильтр по типу занятости.
- **skill_ids** — Требовать наличие всех указанных навыков в резюме.
- **role_type_id** — Фильтр по идентификатору желаемой роли.
- **work_format** — Фильтр по формату работы.
- **commitment_level** — Фильтр по уровню занятости.
- **salary_min** — Минимальная сумма зарплаты.
- **salary_max** — Максимальная сумма зарплаты.
- **computed_experience_level** — Фильтр по вычисленному уровню опыта.
- **created_within_days** — Только резюме, созданные за указанное количество дней.
- **limit** — Максимальное количество возвращаемых строк.
- **offset** — Количество пропускаемых строк.
- **Возвращает** — Элементы результатов публичного поиска резюме.
  - *тип* `list[ResumeSearchItem]`

#### `async def recompute_experience_level(resume_id)`

Пересчитывает и сохраняет вычисленный уровень опыта на основе истории работы.

- **resume_id** — Первичный ключ резюме.

#### `async def has_active_assignment(resume_id)`

Проверяет, есть ли у резюме активное назначение на вакансию.

- **resume_id** — Первичный ключ резюме.
- **Возвращает** — ``True``, если резюме назначено на вакансию.
  - *тип* `bool`

#### `async def set_status(resume_id, status)`

Обновляет жизненный цикл резюме.

- **resume_id** — Первичный ключ резюме.
- **status** — Новое значение статуса резюме.

#### `async def get_active_project_briefs_by_resume_ids(resume_ids)`

Загружает сводки активных проектов для резюме с открытыми назначениями.

- **resume_ids** — Идентификаторы резюме для поиска.
- **Возвращает** — Отображение идентификатора резюме в краткую сводку активного проекта.
  - *тип* `dict[int, ActiveProjectBrief]`

## `src.repositories.users`

### class `UsersRepository`

Репозиторий для сохранённых записей учётных записей пользователей.

#### `async def get_user_with_hashed_password(email)`

Загружает активного пользователя по email, включая хеш пароля.

- **email** — Адрес электронной почты пользователя.
- **Возвращает** — Схема пользователя с хешем пароля.
  - *тип* `UserWithHashedPassword`
- **`Unauthorized`** — Если пользователь с указанным email не найден.
- **`AccessDenied`** — Если учётная запись пользователя заблокирована.

#### `async def get_user_with_hashed_password_by_id(user_id)`

Загружает активного пользователя по id, включая хеш пароля.

- **user_id** — Первичный ключ пользователя.
- **Возвращает** — Схема пользователя с хешем пароля.
  - *тип* `UserWithHashedPassword`
- **`UserNotFound`** — Если пользователь с указанным id не найден.
- **`AccessDenied`** — Если учётная запись пользователя заблокирована.



## `src.repositories.vacancy_assignments`

Доступ к данным назначений на вакансии.

### class `VacancyAssignmentsRepository`

Репозиторий для сохранённых записей назначений резюме на вакансии.

#### `async def get_active_by_vacancy(vacancy_id)`

Возвращает активное назначение для вакансии, если оно есть.

- **vacancy_id** — Первичный ключ вакансии проекта.
- **Возвращает** — Активное назначение или ``None``, если вакансия свободна.
  - *тип* `VacancyAssignment | None`

#### `async def get_active_by_resume(resume_id)`

Возвращает активное назначение для резюме, если оно есть.

- **resume_id** — Первичный ключ резюме.
- **Возвращает** — Активное назначение или ``None``, если резюме не назначено.
  - *тип* `VacancyAssignment | None`

#### `async def release_by_resume(resume_id)`

Снимает все активные назначения для резюме.

- **resume_id** — Первичный ключ резюме.

#### `async def release_all_for_project(project_id)`

Снимает все активные назначения для вакансий проекта.

- **project_id** — Первичный ключ проекта.
- **Возвращает** — Идентификаторы резюме, с которых сняты назначения.
  - *тип* `list[int]`

#### `async def get_active_member_snapshots_for_project(project_id)`

Возвращает идентификаторы пользователей и резюме активных участников проекта.

- **project_id** — Первичный ключ проекта.
- **Возвращает** — Пары ``(user_id, resume_id)`` для активных назначений.
  - *тип* `list[tuple[int, int]]`

#### `async def get_member_user_ids_for_project(project_id)`

Возвращает идентификаторы пользователей активных участников, назначенных на вакансии проекта.

- **project_id** — Первичный ключ проекта.
- **Возвращает** — Идентификаторы пользователей с активными назначениями на проекте.
  - *тип* `list[int]`
